# Shared website working agreements

Before editing, read `../css-shared/AGENTS.md`,
`../css-shared/docs/project-conventions.md`, and
`../css-shared/docs/work-status.md`. They hold the accepted cross-site conventions
and current handoff. If the sibling shared checkout is missing, locate it using
this repository's shared-source configuration; do not guess the conventions.

Follow and maintain those records as part of the task. “Lock this down” means
persist an agreed decision there. Record clear durable decisions proactively too.
Keep page metadata in individual HTML source files; keep reusable layouts and
shared data in the shared repository. Consult the documented scope and exceptions.
Before a machine handoff, distinguish local, committed, pushed, and deployed work;
inspect this repository as well as shared. Preserve unrelated local changes.
